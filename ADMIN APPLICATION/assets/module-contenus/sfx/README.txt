Dépose ici tes petits effets sonores (SFX), déclenchés automatiquement selon
le contenu de chaque scène (voir MCNT_SFX_REGLES dans module-contenus.js) :

- victoire.mp3        (succès, réussite, victoire...)
- impact.mp3          (chute, choc, coup...)
- revelation.mp3      (soudain, découvre, réalise...)
- transition-douce.mp3 (plus tard, le lendemain...)
- notification.mp3    (téléphone, message, notification...)

Même nom de fichier attendu = ça marche automatiquement, aucune modif de code nécessaire.
Tant qu'un fichier est absent, le montage continue normalement, juste sans ce son.
